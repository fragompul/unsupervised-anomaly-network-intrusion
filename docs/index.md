# Noctua

**An interactive research lab for unsupervised network intrusion detection under training
contamination, temporal drift and dataset shift.**

* **Live app:** the web app (3D explorer, benchmark, robustness lab, replay, playground) lives at the
  root of this site.
* **Code:** [github.com/fragompul/unsupervised-anomaly-network-intrusion](https://github.com/fragompul/unsupervised-anomaly-network-intrusion)

Start with the [research protocol](protocol.md), then the [datasets](datasets.md). The
[problem statement](problem_statement.md) and [methodology](methodology.md) pages describe the
original NSL-KDD pipeline that Noctua grew out of.
